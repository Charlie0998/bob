REEF KEEPERS - ORIGINAL SOUND EFFECTS
=====================================
10 short WAV files, mono, 44.1 kHz. Made from scratch, so you own them and can
upload them to Roblox without copyright issues.

FILE                  USE IT FOR                          SUGGESTED VOLUME
harvest.wav           harvesting a coral                  0.5
plant.wav             planting a coral                    0.6
buy_slot.wav          buying a plot slot                  0.6
bubble_pop.wav        small UI pops, tapping creatures    0.5
button_click.wav      every menu button click             0.4
daily_reward.wav      claiming the daily reward           0.7
level_up.wav          reef level up                       0.7
rare_find.wav         rare coral / mutation / new entry   0.7
storm_event.wav       Storm reef event (5 sec)            0.5
ocean_ambience_loop   background ambience (set Looped)    0.2

HOW TO USE THEM
1. Roblox Studio > View > Asset Manager > Bulk Import > pick the .wav files.
   (Audio uploads are checked by Roblox, so approval can take a few minutes.)
2. Right-click each uploaded sound > Copy Asset ID.
3. In the effects script, replace the placeholder ids in the SOUNDS table, e.g.
     harvest = { id = "rbxassetid://YOUR_ID_HERE", volume = 0.5 },
4. For the ocean loop, create a Sound in SoundService, paste its id, and turn
   on Looped and Playing.
